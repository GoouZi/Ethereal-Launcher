# Ethereal Launcher beta 0.4.0

## 界面与交互

- 集中优化页面切换动画、整体流畅度与响应速度。
- 修复页面切换过程中出现的闪黑问题。
- 调整过重的页面过渡动画。
- 重新设计下载完成、游戏启动与错误等状态提示。
- 优化状态提示出现、退出与内容切换动画。
- 提示遮罩层改为独立淡入淡出，减少突兀闪现。
- 统一各类提示框为玻璃质感设计。
- 较长的错误信息与说明内容支持在提示框内滚动查看。
- 精简窗口控制项，移除启动器不需要的全屏入口。

## 下拉菜单与滚动

- 重做自定义下拉菜单的显示层级，避免被页面内容遮挡。
- 修复主页版本下拉框的展开与滚动逻辑。
- 修复较旧 macOS 上原生下拉菜单被异常拉长的问题。
- 下拉菜单根据选项数量动态调整高度，内容较多时自动启用滚动。
- 优化滚动区域上下边缘的渐隐效果。
- 移除版本管理卡片多余的白色边缘。

## 实例管理

- 将游玩时间统计整合进版本管理，每个实例独立记录。
- 删除实例时同步清理对应游玩时间记录。
- 新增实例重命名。
- 重命名时同步更新文件夹、JSON、JAR、界面名称与游玩时间记录。
- 实例重名时自动生成可用名称，避免覆盖已有版本。

## 自定义背景

- 加入自定义背景缓存，减少页面切换时重复读取造成的闪烁。
- 更新 macOS 文件选择接口，改善不同系统版本上的背景选择兼容性。
- 自定义背景新增 MOV、MP4、M4V 视频支持。
- 视频背景静音并循环播放。
- 视频背景加入首帧缩略图预览。
- 支持连续更换图片或视频背景并立即生效，无需重启启动器。
- 简化背景设置界面，不再直接显示所选文件名。
- 降低自定义背景上的遮罩强度，保留更多原始画面细节。

## 下载中心与 Modrinth

- 重构下载中心，新增 Minecraft、模组、材质包与光影四个独立分类。
- Minecraft 下载支持原版、Fabric 与 Forge。
- 安装 Minecraft 时可自定义实例名称。
- 接入 Modrinth，可按分类搜索模组、材质包与光影。
- 支持按下载量浏览热门 Modrinth 资源。
- 安装资源时可选择目标 Minecraft 实例。
- 模组、材质包与光影分别安装到 mods、resourcepacks 与 shaderpacks 目录。
- 为模组、材质包与光影提供独立的排行榜与搜索体验。
- 点击 Minecraft 版本后可在安装弹窗中直接选择原版、Fabric 或 Forge。

## 加载器与兼容性

- 修复 Fabric Loader 部分 Maven 依赖与 Classpath 不完整导致的启动问题。
- 改进 Fabric、Forge 与 NeoForge 实例识别。
- 兼容带加载器后缀的自定义实例名称。
- 优化 Modrinth 兼容性判断，不再只依赖 featured 版本。
- 放宽材质包不必要的严格 Minecraft 版本限制。
- 放宽光影包版本检查。
- 光影安装仅提供给适合的加载器环境，减少安装后无法使用的情况。

## 稳定性与后台任务

- 重新实现 Dock 下载进度并多次修正显示稳定性。
- 修复部分界面尺寸约束导致的构建与布局兼容问题。
- 改进后台进程输出缓冲与线程安全处理。
- 提升游戏下载与 Java 安装进行时的界面稳定性。
- 调整 Logo 与版本信息展示位置，设置页底部加入版本与版权信息。
