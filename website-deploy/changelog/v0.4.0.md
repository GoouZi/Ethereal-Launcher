# Ethereal Launcher beta 0.4.0

## 新增

- 新增 Minecraft 实例重命名，并同步更新实例文件与相关记录。
- 自定义背景新增 MOV、MP4、M4V 视频支持，可静音循环播放。
- 视频背景加入首帧预览，并支持图片与视频背景即时切换。
- 重构下载中心，新增 Minecraft、模组、材质包与光影四个分类。
- Minecraft 安装支持原版、Fabric 与 Forge，并可自定义实例名称。
- 接入 Modrinth，可搜索模组、材质包和光影，并浏览热门资源。
- 安装资源时可直接选择目标 Minecraft 实例。

## 改进

- 集中优化页面切换、提示框、滚动与整体动画流畅度。
- 统一提示窗口视觉，并支持较长错误信息滚动查看。
- 重做下拉菜单，使其不再容易被页面内容遮挡。
- 下拉菜单可根据内容数量自动调整高度并启用滚动。
- 优化旧版 macOS 上的下拉控件兼容性。
- 加入自定义背景缓存，减少切换页面时的重复加载和闪烁。
- 更新背景文件选择体验，改善不同 macOS 版本上的兼容性。
- 重新实现 Dock 下载进度，提高下载过程中的显示稳定性。
- 将游玩时间整合进版本管理，并按实例独立记录。
- 优化游戏下载与 Java 安装期间的后台任务稳定性。
- 改进 Modrinth 资源兼容性判断。
- 放宽材质包与光影包中过于严格的版本限制。

## 修复

- 修复部分 Fabric Loader Maven 依赖不完整导致的启动失败。
- 修复部分 Fabric Classpath 不完整的问题。
- 改进 Fabric、Forge 与 NeoForge 实例识别。
- 修复背景频繁切换时的闪烁与延迟问题。
- 修复实例重命名时可能出现的文件名、记录不同步和重名问题。
- 修复部分滚动区域与提示动画显示异常。
