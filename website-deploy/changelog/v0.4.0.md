# Ethereal Launcher beta 0.4.0

- 集中优化页面切换、弹窗、下拉菜单、滚动渐隐与整体界面流畅度。
- 新增 Minecraft 实例重命名，并同步更新实例目录、JSON、JAR 与相关记录。
- 自定义背景新增 MOV、MP4、M4V 视频支持，可静音循环播放、显示首帧预览并即时切换。
- 重构下载中心，加入 Minecraft、模组、材质包与光影四个分类。
- Minecraft 安装支持原版、Fabric 与 Forge，并支持自定义实例名称。
- 接入 Modrinth，可搜索并浏览热门模组、材质包与光影。
- 安装资源时可选择目标实例，并加入 Minecraft 版本与模组加载器兼容性判断。
- 修复部分 Fabric Maven 依赖与 Classpath 问题，并改进 Fabric、Forge、NeoForge 实例识别。
- 优化后台下载、Java 安装、Dock 进度及旧版 macOS 上的界面稳定性。

发布日期：2026-06-21
