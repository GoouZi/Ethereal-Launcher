# Ethereal Launcher 0.9.0

- 本地版本管理会识别 Fabric、Forge、NeoForge 与 Quilt；原版版本不再显示 Mods 和光影包入口，原版与加载器版本卡片保持统一高度和操作层级。
- 加载器版本新增“管理模组”界面，显示 Modrinth 项目名称和图标，可以直接启用或禁用 JAR，并按当前 Minecraft 版本与加载器执行单个更新或全部更新。更新包会核对文件大小与 SHA 校验，替换失败时恢复原文件。
- Modrinth 模组、材质包与光影包图片增加内存与磁盘缓存、页面预取和更高的连接并发，重复进入页面时加载更快。
- 版本下载标签切换不再让版本列表参与选中动画，避免卡片短暂跳动。
- 重新设计应用更新界面，采用更紧凑的 Sparkle 式信息布局，并保持 Ethereal Launcher 的材质、字体和圆角规范。
