# Ethereal Launcher beta 0.3.0

## Java 与启动兼容

- 完善新版 Minecraft 所需的 Java 25 下载、安装与识别。
- Java 下载加入 JDK / JRE 回退机制。
- Apple Silicon 优先选择 ARM64 Java，并加入架构回退。
- 改进不同 Minecraft 版本所需 Java 的自动判断与选择。
- 修复 macOS 启动 Minecraft 所需的 -XstartOnFirstThread 参数处理。
- 启动前增加依赖库完整性检查，减少缺失文件导致的启动失败。
- 调整游戏窗口与启动参数兼容性。

## 实例与版本管理

- 支持同一 Minecraft 版本使用不同名称创建多个实例。
- 新增本地 Minecraft 版本管理页面，可自动扫描已安装实例。
- 版本卡片显示实例名称、Minecraft 版本、实例类型、Java 与修改时间等信息。
- 支持将实例设为当前启动版本。
- 支持快速打开版本目录与相关 Minecraft 目录。
- 支持删除实例，并加入删除确认与列表刷新。
- 版本管理重新进入时自动回到顶部。

## 玩家与版本筛选

- 新增玩家名称合法性检查，仅允许 3–16 位字母、数字与下划线。
- 版本筛选扩展为正式版、预览版、愚人节版与远古版。
- 版本筛选支持多选，并确保至少保留一个分类。

## 界面与导航

- 将版本管理整合到底部主导航。
- 扩大导航按钮实际点击区域，同时保持原有视觉尺寸。
- 加入更自然的弹簧动画、按压反馈与页面淡入淡出。
- 重新调整下载页与设置页标题、留白和内容对齐。
- 优化主页、版本管理、下载与设置之间的页面结构。
- 下载列表改用懒加载布局，改善长列表滚动性能。

## 下载体验

- 重做 Minecraft 版本选择控件，修复部分 macOS 版本上原生下拉菜单显示异常。
- 新增 Dock 下载进度与百分比显示。
- 下载完成后自动返回主页并显示完成提示。
- 游戏成功启动后显示状态提示。
- 下载页首次载入时加入加载动画。
- 为滚动区域加入边缘渐隐和额外留白。

## 个性化与系统菜单

- 新增自定义图片背景。
- 自定义背景保存到应用数据中并在重启后保留。
- 支持一键恢复默认背景。
- 精简 macOS 原生菜单与无关功能。
- 菜单改用中文文案，并保留必要的关于与退出入口。
