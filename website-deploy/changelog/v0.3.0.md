# Ethereal Launcher beta 0.3.0

## 新增

- 新增本地 Minecraft 版本管理，可自动扫描并管理已安装实例。
- 版本卡片显示实例名称、Minecraft 版本、类型、Java 与修改时间。
- 支持设置当前实例、打开实例目录和删除实例。
- 支持同一个 Minecraft 版本创建多个不同名称的实例。
- 新增玩家名称合法性检查。
- 新增自定义图片背景，并支持恢复默认背景。
- 新增 Dock 下载进度与百分比显示。
- 版本筛选加入愚人节版本，并支持多分类选择。

## 改进

- 完善新版 Minecraft 所需 Java 25 的下载、识别与自动选择。
- Java 下载加入 JDK / JRE 回退，并改进 Apple Silicon / Intel 架构选择。
- 启动游戏前检查缺失依赖，减少文件不完整导致的启动失败。
- 版本管理正式加入主导航。
- 优化导航点击区域、页面切换动画与长列表滚动性能。
- 重新设计 Minecraft 版本选择控件。
- 下载完成与游戏启动成功后加入状态提示。
- 优化下载页加载动画、滚动渐隐与页面留白。
- 精简 macOS 菜单栏中的无关菜单项。

## 修复

- 修复部分 macOS 版本上原生版本选择菜单显示异常的问题。
- 完善 macOS 游戏启动参数处理，降低不同 Minecraft / Java 组合下的启动失败概率。

发布日期：2026-06-12
