# Ethereal Launcher beta 0.3.0

- 完善新版 Minecraft 所需的 Java 25 下载、识别、JDK / JRE 回退与架构选择。
- 新增本地 Minecraft 版本管理，可扫描、选择、打开目录和删除已安装实例。
- 支持同一 Minecraft 版本创建多个不同名称的实例，并加入玩家名称合法性检查。
- 启动前增加依赖完整性检查，并继续完善 macOS 启动参数兼容。
- 将版本管理整合进主导航，优化页面切换、导航点击区域与长列表滚动性能。
- 新增 Dock 下载进度与状态提示。
- 新增自定义图片背景，并支持恢复默认背景。
- 版本筛选加入愚人节版本与多选逻辑，优化下载页加载和滚动效果。

发布日期：2026-06-12
