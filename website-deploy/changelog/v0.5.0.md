# Ethereal Launcher beta 0.5.0

## 跨版本数据迁移

- 下载新的 Minecraft 版本时，可选择一个已安装实例作为数据来源。
- 可选择迁移游戏设置、服务器列表、存档、材质包、光影包、截图、模组与模组配置。
- 常用数据默认选中，模组与模组配置需要用户主动选择。
- 迁移会在新 Minecraft 版本及所选模组加载器安装完成后执行。
- 迁移过程不会修改来源实例。
- 来源与目标共用同一游戏目录时自动跳过重复复制。
- 拒绝迁移符号链接，避免将实例外部文件意外带入目标版本。
- 文件替换使用临时文件完成，降低迁移中断后留下损坏文件的风险。
- 版本设置保存成功后自动关闭窗口。

## 智能模组迁移

- 原版目标实例不会迁移模组与模组配置。
- 仅当来源与目标使用相同模组加载器时，才允许迁移模组相关内容。
- Minecraft 版本与加载器完全相同时，直接迁移原有模组文件。
- Minecraft 版本发生变化时，不直接复制旧版模组 JAR。
- 通过模组文件 SHA-1 在 Modrinth 识别来源模组。
- 自动查找适用于目标 Minecraft 版本及相同加载器的兼容模组版本。
- 自动逐个下载目标版本兼容的模组文件。
- 保留模组原来的启用或禁用状态。
- 下载后的模组会校验文件大小、SHA-512 或 SHA-1。
- 无法识别、没有兼容版本或校验失败的模组会跳过并记录，不会将不兼容文件直接放入新实例。

## 模组与资源管理

- 新增模组管理页面。
- 支持直接启用与禁用已安装模组。
- 支持手动检查单个模组更新。
- 支持检查全部模组更新。
- 支持更新单个模组或全部可更新模组。
- 模组更新校验通过后直接替换旧 JAR，避免同一模组的新旧文件同时存在。
- 接入 Modrinth 项目信息，显示更友好的模组名称与图标。
- 优化模组、材质包与光影图片缓存和预取，减少重复等待。
- 模组管理页不再在打开时自动连接 Modrinth，更新检查改为用户主动触发。
- 模组、材质包与光影安装到当前实例实际使用的游戏目录，并在写入后进行文件校验。

## Minecraft 下载与加载器

- 下载 Minecraft 时不再无条件显示 Fabric 与 Forge 选项。
- 根据目标 Minecraft 版本查询 Fabric、Forge 等加载器的实际支持情况。
- 没有对应加载器支持的 Minecraft 版本只显示原版。
- 加载器支持信息查询失败时显示重试入口，不会将“查询失败”误判为“支持安装”。
- 新增 Fabric、Forge、NeoForge 与 Quilt 本地实例识别，并统一原版与加载器实例的卡片显示。
- 修复 Fabric / Forge 覆盖原版游戏参数与 JVM 参数的问题。
- 启动前可修复旧加载器配置，同时保留存档、模组与设置。
- 修复 Forge 安装结果识别与部分安装失败问题。
- 改进下载取消后的清理与解锁逻辑。
- 加强实例安装与删除目录的安全保护，并统一版本与启动器标识。

## Java、内存与实例设置

- 新增自动内存分配。
- 新增全局 Java 管理，可自动下载并选择适合目标 Minecraft 的 Java。
- 支持使用自定义 Java，并在启动前验证 Java 版本。
- 新增版本隔离，可选择关闭、仅隔离加载器版本或隔离全部版本。
- 新增单独版本设置，可覆盖全局隔离、完整性检查、Java 与内存策略。
- 新增游戏窗口尺寸与启动后行为设置。
- 优化 Native Libraries 复用与游戏启动性能。
- 版本设置保存或恢复全局设置后自动关闭。

## 完整性检查与修复

- 增强 Minecraft 游戏文件完整性校验。
- 损坏或不完整的游戏下载会自动重试。
- 完整性检查加入缓存，减少重复检查开销。
- 支持从设置页手动检查与修复游戏文件。
- 启动前可修复缺失或异常的游戏文件，同时保留用户存档、模组和设置。
- Java、依赖库与原生库继续执行大小及哈希校验。

## 旧版 Minecraft 与 Apple Silicon 兼容

- 修复 Minecraft 1.8.9 错误尝试下载不存在的 jinput-platform-2.0.5.jar 导致 HTTP 404 的问题。
- 正确区分普通依赖与仅包含原生库 classifier 的平台依赖。
- 恢复按照官方版本规则选择 LWJGL，不再错误强制统一为另一个版本。
- 修正旧版 Minecraft 的 Classpath 与原生库解析逻辑。
- 修复旧版只有声音但没有窗口的主要问题：不再为所有 Minecraft 无条件加入 -XstartOnFirstThread。
- LWJGL 2 游戏不添加 -XstartOnFirstThread，LWJGL 3 游戏继续保留该参数。
- 修复游戏窗口尚未创建时启动器就提前显示“启动成功”的问题。
- 避免同一个 Minecraft 实例重复启动；重复点击时尝试唤醒已有窗口。
- 兼容路径保持官方版本元数据，不修改原始 Minecraft JAR 与版本 JSON。
- Apple Silicon 上的原版 LWJGL 2 游戏自动使用独立 ARM64 Java 8。
- 自动准备 ARM64 LWJGL 2.9.4 与 JInput 原生库。
- Java 下载使用固定 SHA-256 校验。
- 自定义 Java、Fabric、Forge 与 NeoForge 实例不会被旧版兼容逻辑强制替换。

## 旧版声音、资源与早期版本渲染

- 修复旧 OpenAL 在现代 macOS 上初始化失败的问题。
- 在可用时改用 LWJGL 2 自带的系统 OpenAL 回退。
- 根据资源索引自动处理 virtual、map_to_resources 与 ${game_assets}。
- 为旧 Minecraft 创建其实际需要的具名资源目录。
- 已存在的自定义声音与材质文件不会被覆盖。
- 为 Alpha、Beta、Infdev 等早期原版接入专门的旧版窗口与资源兼容路径。
- 修复 Apple Silicon 上部分早期版本红蓝颜色通道颠倒。
- 修复 Infdev 创建或进入世界后黑屏的问题。
- 旧版兼容继续使用 LWJGL 2，不重新采用此前表现异常的 LWJGL 3 桥接方案。
- 补充相关第三方组件许可证。
