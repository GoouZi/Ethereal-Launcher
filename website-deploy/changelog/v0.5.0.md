# Ethereal Launcher beta 0.5.0

## 重点更新

- Ethereal Launcher 首个公开 Beta 版本。
- 新增跨版本游戏数据迁移：下载新 Minecraft 版本时，可从已有实例迁移设置、服务器列表、存档、材质包、光影、截图、模组与模组配置。
- 新增智能模组迁移：当 Minecraft 版本变化时，可通过 Modrinth 自动识别现有模组，并下载适用于目标版本和相同加载器的兼容版本。
- 大幅改善旧版 Minecraft 在现代 macOS 与 Apple Silicon Mac 上的运行兼容性。
- 新增完整的模组管理与更新功能。
- 接入 Sparkle 2 应用内更新。

## Minecraft 与实例管理

- 新增自动内存分配。
- 新增全局 Java 管理，可自动下载并选择适合当前 Minecraft 的 Java。
- 支持自定义 Java，并在使用前检查 Java 版本。
- 新增版本隔离，可选择关闭、仅隔离加载器版本或隔离全部版本。
- 新增单独版本设置，可覆盖全局 Java、内存、版本隔离与完整性检查设置。
- 新增游戏窗口尺寸与启动后行为设置。
- 增强游戏文件完整性检查，并支持手动检查与修复。
- 完整性检查加入缓存，减少不必要的重复扫描。
- 启动前可修复旧加载器配置与缺失文件，同时保留存档、模组和设置。
- 避免同一个 Minecraft 实例重复启动；再次启动时优先唤醒已经运行的游戏窗口。
- 改进启动状态判断，只有游戏窗口真正创建后才视为启动成功。

## 模组与资源

- 新增模组管理，可直接启用或禁用已安装模组。
- 支持检查单个模组更新与全部模组更新。
- 支持直接更新单个或全部可更新模组。
- 更新模组时自动替换旧版 JAR，避免同一模组多个版本同时存在。
- 接入 Modrinth 项目信息，显示更友好的模组名称与图标。
- 优化模组、材质包与光影图片缓存和预取。
- 下载新版本时，只有来源与目标使用兼容的模组加载器才会提供模组迁移。
- Minecraft 版本变化时，不再直接复制可能不兼容的旧模组，而是自动寻找对应版本。
- 保留迁移模组原有的启用 / 禁用状态。
- 无法识别、没有兼容版本或文件校验失败的模组会被跳过。
- 模组、材质包与光影会安装到实例实际使用的游戏目录。

## 下载与加载器

- 下载 Minecraft 时根据目标版本实际支持情况显示 Fabric、Forge 等加载器选项。
- 不支持对应加载器的 Minecraft 版本只显示可用选项。
- 加载器支持信息查询失败时提供重试，不再把查询失败误认为可安装。
- 本地版本管理新增 Fabric、Forge、NeoForge 与 Quilt 识别。
- 统一原版与模组加载器实例的版本卡片显示。
- 修复 Fabric / Forge 覆盖原版游戏参数与 JVM 参数的问题。
- 改进 Forge 安装结果识别与安装失败处理。
- 改进下载取消后的清理与恢复逻辑。

## 旧版 Minecraft 兼容

- 修复 Minecraft 1.8.9 下载不存在的 jinput-platform-2.0.5.jar 导致 HTTP 404 的问题。
- 修复旧版 Minecraft 的 Classpath 与原生库解析。
- 恢复按照各版本官方依赖选择 LWJGL，不再强制替换为统一版本。
- 修复部分旧版 Minecraft 只有声音但没有游戏窗口的问题。
- 根据实际 LWJGL 版本选择 macOS 启动方式：LWJGL 2 不再错误加入 -XstartOnFirstThread，LWJGL 3 保留该参数。
- Apple Silicon 上的原版 LWJGL 2 Minecraft 自动使用独立 ARM64 Java 8。
- 为 Apple Silicon 自动准备兼容的 LWJGL 2.9.4 与 JInput 原生库。
- 修复旧版 OpenAL 在现代 macOS 上无法正常初始化声音的问题。
- 完善旧资源系统兼容，支持 virtual、map_to_resources 与 ${game_assets} 等资源结构。
- 改善 Alpha、Beta 与 Infdev 等早期 Minecraft 版本的窗口、资源和渲染兼容性。
- 修复 Apple Silicon 上部分早期版本红蓝颜色通道颠倒的问题。
- 修复 Infdev 创建或进入世界后黑屏的问题。
- 兼容处理不会修改官方 Minecraft JAR 与原始版本 JSON。
- 自定义 Java、Fabric、Forge 与 NeoForge 实例不会被旧版兼容方案强制替换。

## 界面与体验

- 重构设置中心，划分为游戏、个性化与关于三个分类。
- 重新设计 Minecraft 版本下载分类，并显示发布日期与 Java 要求。
- 统一主页与设置中的自定义下拉控件。
- 改进下拉菜单悬停、点击外部关闭、滚动和过渡动画。
- 统一游戏下载、检查更新、版本设置、模组管理、检查修复、提示、确认与输入窗口的视觉语言。
- 重新设计弹窗布局、按钮层级、半透明材质、阴影和入场动画。
- 优化 macOS“减少动态效果”与“减少透明度”开启时的显示效果。
- 优化页面切换、键盘操作、VoiceOver 与外部链接体验。
- 优化 macOS 12.4 上的界面兼容性。
- 设置页版权信息更新为“© 2026 Goou_Zi”。

## 应用更新

- 接入 Sparkle 2，支持在启动器内检查、下载、安装更新并重新启动。
- 新增启动时后台检查更新。
- 后台检查仅在发现新版本时提示，已是最新版或临时检查失败时保持静默。
- 保留手动“检查更新”入口，并显示完整的检查结果与错误信息。
- 重新设计更新窗口，使版本说明和更新状态更清晰。

## 修复与优化

- 增强 Minecraft、Java、依赖库与原生库的文件校验。
- 损坏或不完整的下载会自动重新获取。
- 优化 Native Libraries 复用与游戏启动性能。
- 加强实例安装与删除时的目录安全处理。
- 修复部分模组迁移与并发处理问题。
- 优化资源下载、缓存与安装过程中的稳定性。
