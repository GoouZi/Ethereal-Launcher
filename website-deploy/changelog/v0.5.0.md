# Ethereal Launcher beta 0.5.0

- 增强 Minecraft 游戏文件完整性检查与自动修复，并改进 Fabric、Forge、NeoForge、Quilt 等加载器实例的识别与启动兼容性。
- 新增自动内存、Java 管理、版本隔离、窗口尺寸、启动后行为等全局设置，并支持单独实例覆盖全局设置。
- 重构设置中心与版本下载界面，补充 Minecraft 发布日期、Java 要求等信息，并优化键盘、VoiceOver、减少动态效果与减少透明度等 macOS 辅助功能体验。
- 统一主页和设置中的下拉控件，并加入更自然的悬停、关闭与过渡交互。
- 新增模组管理，可启用、禁用、检查更新并更新单个或全部模组；接入 Modrinth 项目信息并优化资源图片缓存。
- 接入 Sparkle 2 应用内更新，支持检查、查看更新内容、下载、安装与重启，并加入启动时静默后台检查更新。
- 新增跨版本游戏数据迁移。下载新版本时可选择从已有实例迁移游戏设置、服务器列表、存档、材质包、光影、截图、模组与模组配置。
- 新增智能模组迁移：仅在加载器兼容时迁移模组；Minecraft 版本变化时通过 Modrinth 自动识别来源模组并下载目标版本的兼容文件。
- 模组迁移会保留启用或禁用状态，并校验下载文件；无法识别、没有兼容版本或校验失败的模组会安全跳过。
- 下载 Minecraft 时根据目标版本实际支持情况显示 Fabric / Forge 等加载器选项，避免为不支持的版本提供无效安装入口。
- 统一游戏下载、版本设置、模组管理、检查修复、提示、确认与输入窗口的弹窗设计，并适配 macOS 的减少动态效果与减少透明度设置。
- 大幅改善旧版 Minecraft 在现代 macOS 上的兼容性，修复 1.8.9 部分依赖 404、Classpath、原生库解析以及只有声音没有窗口等问题。
- 根据 LWJGL 版本自动选择正确的 macOS 启动方式；原版 LWJGL 2 游戏在 Apple Silicon 上自动使用独立 ARM64 Java 8 与兼容原生库。
- 修复旧版 OpenAL 在现代 macOS 上的声音初始化问题，并完善 virtual、map_to_resources、${game_assets} 等旧资源结构。
- 改善 Alpha、Beta、Infdev 等早期 Minecraft 版本在 Apple Silicon 上的渲染与窗口兼容性，修复部分版本红蓝通道颠倒和进入世界黑屏的问题。
- 避免同一个 Minecraft 实例重复启动，并改进游戏窗口真正创建后的启动成功判断。
- 保持官方 Minecraft JAR 与版本 JSON 不被兼容层直接修改，并继续对 Java、依赖与原生库执行完整性校验。
- 已验证 Minecraft 1.8.9、Alpha 1.2.6、Infdev inf-20100618、1.6.4 与 rd-132211 可正常运行；Intel 与 Apple Silicon 通用 Release 构建及 29 项自动测试通过。
