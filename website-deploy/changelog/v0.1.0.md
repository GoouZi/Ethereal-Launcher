# Ethereal Launcher beta 0.1.0

## Minecraft 启动

- 完成 macOS 原生 Minecraft 启动器基础界面与启动流程。
- 根据 Minecraft 版本 JSON 自动组织游戏参数、JVM 参数与 Classpath。
- 自动准备游戏所需的 Client、依赖库与原生库。
- 适配 macOS 所需的启动参数与原生库加载方式。
- 完成 Minecraft 1.21.11 的实际启动验证，可从启动器正常进入游戏主菜单。

## Java 运行环境

- 实现 Java 运行环境的自动下载与准备，无需用户手动安装 Java。
- 根据 Minecraft 版本需求选择对应 Java 运行环境。
- 为首次启动加入基础状态与错误反馈。

## 基础交互

- 支持设置玩家名称并从启动器直接启动 Minecraft。
- 建立最初的游戏下载、环境准备与启动闭环。
