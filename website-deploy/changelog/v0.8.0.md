# Ethereal Launcher 0.8.0

- 项目、Target、应用包与应用内名称统一为 Ethereal Launcher，并迁移旧版偏好与游戏数据目录。
- 统一主页和设置页下拉框，使用不会被主窗口边界裁切的独立浮层。
- 重绘 Minecraft 版本分类标签栏，使其与侧边栏、卡片和按钮风格一致。
- 通过 Swift Package Manager 集成 Sparkle 2，接入应用内检查、更新日志、下载、EdDSA 验证、替换与重启流程。
- 更新 Feed 使用 `https://emcl.goouzi.top/update/appcast.xml`，EdDSA 私钥仅保存在开发 Mac 登录 Keychain。
