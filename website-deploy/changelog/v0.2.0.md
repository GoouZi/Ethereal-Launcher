# Ethereal Launcher beta 0.2.0

## 界面与导航

- 重做启动器主界面，加入 Minecraft 场景背景、图形 Logo 与半透明控件。
- 建立主页、下载与设置三个主要页面。
- 主页加入 READY TO EXPLORE、玩家名称、版本选择与 LAUNCH GAME 主操作区。
- 底部导航扩展为主页、下载与设置三栏。
- 统一窗口、卡片、按钮与半透明控件的视觉样式。

## Minecraft 下载

- 接入 Minecraft 官方版本列表。
- 支持正式版、预览版与远古版本等分类与筛选。
- 加入 BMCLAPI2 镜像支持。
- 完善 Client、Libraries、Assets 与原生库的自动下载。
- 加入并发下载，提高完整游戏安装速度。
- 加入下载进度、实时日志、取消下载与失败反馈。

## Java 与平台适配

- 根据 Apple Silicon 与 Intel 架构自动选择合适的 Java。
- 支持自动管理 Java 8、Java 17、Java 21 等不同运行环境。
- 继续完善 macOS -XstartOnFirstThread 与 Native 解压处理。

## 设置与统计

- 设置页加入游戏内存分配。
- 新增按 Minecraft 版本记录的游玩时间统计。
- 新增总游玩时间统计。

## 细节优化

- 完善用户名、本地版本选择与一键启动流程。
- 优化下载完成和启动过程中的状态反馈。
