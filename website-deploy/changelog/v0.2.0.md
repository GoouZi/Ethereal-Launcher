# Ethereal Launcher beta 0.2.0

- 重做启动器界面，建立主页、下载与设置三个主要页面，并加入背景、Logo 与半透明控件。
- 接入 Minecraft 官方版本列表，支持正式版、预览版、远古版本等分类与筛选。
- 加入 BMCLAPI2 镜像，并完善 Client、Libraries、Assets 与原生库的自动下载。
- 加入并发下载、进度、日志、取消与失败反馈。
- 根据 Apple Silicon / Intel 架构自动管理 Java 8、17、21 等运行环境。
- 设置中加入游戏内存分配，并新增单版本与总游玩时间统计。

发布日期：2026-01-18
