# Ethereal Launcher

[简体中文](./README.md) | [English](./README_EN.md)

**Ethereal Launcher (EMCL)** is a Minecraft launcher built specifically for macOS.

Launching should be simple.

Ethereal Launcher is designed for Mac users who do not want to spend time learning Java environments, dependency setup, or complicated launcher configuration before they can play Minecraft. The focus is on a native macOS experience, a lightweight design, clear interaction, and an onboarding flow that makes sense from the first launch.

## Highlights

- **Made for macOS** — Interface and interaction are designed around Mac usage patterns.
- **Native build** — Built with Swift and native macOS frameworks.
- **Beginner friendly** — Reduces the need to manually configure Java, dependencies, and runtime environments.
- **Lightweight by design** — Focused on the core tasks of downloading, managing, and launching Minecraft.
- **Version management** — Manage installed Minecraft versions and switch between them quickly.
- **Game download and installation** — Download and install Minecraft versions directly from the launcher.

## Getting Started

1. Download and open Ethereal Launcher.
2. Choose a Minecraft version.
3. Download the game.
4. Start playing.

Leave the complicated parts to Ethereal Launcher.
