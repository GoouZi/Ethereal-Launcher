# Ethereal Launcher

[简体中文](./README.md) | [English](./README_EN.md)

**Ethereal Launcher (EMCL)** 是一款专为 macOS 打造的 Minecraft 启动器。

启动，本该如此简单。

Ethereal Launcher 希望让不熟悉 Java、运行环境或各种依赖配置的 Mac 用户，也能更轻松地下载、管理并启动 Minecraft。我们更在意的是原生、轻量、清晰，以及第一次打开时就知道下一步该做什么。

## 特点

- **为 macOS 而生** — 界面与交互围绕 Mac 使用习惯设计。
- **原生构建** — 使用 Swift 与 macOS 原生框架打造。
- **小白友好** — 尽量减少手动配置 Java、依赖和复杂环境的需要。
- **轻量克制** — 不堆砌无关功能，专注于 Minecraft 的下载、管理与启动。
- **版本管理** — 直观管理已安装的 Minecraft 版本，并快速切换。
- **游戏下载安装** — 在启动器内完成 Minecraft 版本下载与安装流程。

## 使用方式

1. 下载并打开 Ethereal Launcher。
2. 选择需要的 Minecraft 版本。
3. 下载游戏。
4. 开始游戏。

复杂的部分，交给 Ethereal Launcher。
